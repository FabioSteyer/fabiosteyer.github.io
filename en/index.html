concurrent-file-writesPython · stdlib

When four processes write the same file

Appending in parallel loses data without anyone noticing. The comparison run puts the naive and the coordinated approach side by side and measures the difference.

20expected14lost, naive18gaps in the hash chain0coordinated

Every write records a before and after hash in a journal; a gap in that chain proves someone wrote outside the procedure. The bug only surfaced in the four-process run, while single-process tests stayed green throughout. 18 tests.
