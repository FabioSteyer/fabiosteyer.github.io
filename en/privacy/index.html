Technical state of this site

  • Fully static site. No backend, no database, no contact form.
  • No cookies, no tracking, no analytics, no social media embeds.
  • No external fonts. The fonts used are served from the same server as the site; no connection is made to a font service such as Google Fonts.
  • Scripts and stylesheets are served from the same server as the site, not from external services.
  • JavaScript controls animations and interactive examples using synthetic data. Calculations run locally in the browser. Inputs in these examples are neither stored nor transmitted.
