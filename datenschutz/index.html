Technischer Stand dieser Seite

  • Rein statische Seite. Es gibt kein Backend, keine Datenbank und kein Kontaktformular.
  • Keine Cookies, kein Tracking, keine Analysewerkzeuge, keine Einbindung sozialer Netzwerke.
  • Keine externen Schriftarten. Die verwendeten Schriften liegen auf demselben Server wie die Seite; es wird keine Verbindung zu einem Schriftendienst wie Google Fonts aufgebaut.
  • Skripte und Stilvorlagen werden vom selben Server wie die Seite geladen, nicht von externen Diensten.
  • JavaScript steuert Animationen und interaktive Beispiele mit erfundenen Daten. Die Berechnungen laufen lokal im Browser. Eingaben in diesen Beispielen werden weder gespeichert noch übertragen.
